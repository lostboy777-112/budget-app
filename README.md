# 予算管理

iPhone で使う、個人用の予算アプリです。インストールできるウェブアプリ（PWA）で、ビルドはありません。

公開ページ: https://lostboy777-112.github.io/budget-app/

月ごとの予算と支出を、開いた端末の中だけに記録します。電波がなくても使えます。Google スプレッドシートへのコピーは任意です。

## 機能

- 表示中の月は、日本時間（Asia/Tokyo）の今日が属する月から始まります。‹ › で前の月、次の月へ移ります。見出しは「2026年11月」のような表記です。
- 最初のカテゴリは、食費、日用品、交通、光熱費、通信、娯楽、医療、衣服、その他です。設定（☰）で名前の変更（20文字まで）、追加、削除ができます。
- 予算は月とカテゴリの組み合わせです。「予算を設定」で金額を入れ、0 より大きい整数だけが保存されます。空欄や 0 は、そのカテゴリの予算なしです。
- 前の月に予算があると、「前月の予算をコピー」が出ます。押すと入力欄に入るだけで、この時点では保存も送信もされません。「保存」で確定します。「やめる」で捨てられます。
- 支出は、金額（1円以上の整数）、カテゴリ、日付、メモ（任意、80文字まで）です。一覧の行を開くと編集でき、削除もできます。日付がいま見ている月の外なら、その月の画面に移ります。今日の初期値は日本時間です。
- 画面上部に、残りの予算、今月の予算、使った金額が出ます。残りがマイナスのときは、予算オーバーの表示になります。使った金額には、削除したカテゴリに残っている支出も入ります。今月の予算は、いまあるカテゴリだけを足します。
- カテゴリごとに、使った額と予算、残り、割合、進捗バーが出ます。予算があるとき、使用率が 80% 以上で警告色、予算を超えると危険色です。バーの幅は 100% で頭打ちになり、表示上の割合は 999% までです。予算が未設定で支出だけあるときは「予算未設定」と出ます。
- 設定の「書き出す」は、カテゴリ、予算、支出を JSON ファイル（`budget-日付.json`）でダウンロードします。「読み込む」は、同じ形の JSON で今の記録を置き換えます。置き換えの前に確認が出ます。

## iPhone への入れ方

ホーム画面への追加は Safari から行います。Chrome では、この手順で追加しません。

1. Safari で https://lostboy777-112.github.io/budget-app/ を開きます。
2. 共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。名前は「予算管理」です。
4. 追加したアイコンから開きます。単体のアプリとして起動します。

更新を取り込むときは、アプリをアプリ切り替えから完全に終了して、開き直します。それでも古い画面のままなら、ホーム画面のアイコンを削除して、Safari からもう一度追加します。

## 毎日の使い方

1. 「予算を設定」で、その月のカテゴリ別の金額を入れて保存します。前月と同じなら、コピーしてから保存できます。
2. 「支出を記録」で、使った金額を残します。あとから行を開いて直せます。
3. 上部の残りと、カテゴリのバーで、あとどれだけ使えるかを見ます。
4. ‹ › で別の月へ移動します。月ごとの予算と、その月の支出だけが集計されます。

## データの保存

記録の本体は、その端末のブラウザ内です。

| キー | 内容 |
| --- | --- |
| `budget-app-v1` | カテゴリ、月ごとの予算、支出。アプリの正本です。 |
| `budget-app-sync-v1` | スプレッドシートの送信先 URL、合言葉、未送信のキュー、最終送信時刻、最後のエラー。 |

`budget-app-v1` の形は次のとおりです。

- `categories`: `{ id, name }` の配列
- `budgets`: `"YYYY-MM"` をキーにし、その中はカテゴリ ID と金額
- `expenses`: `{ id, amount, date, categoryId, memo, createdAt }` の配列

公開ページは記録を受け取りません。連携を設定する前の変更もキューには残りますが、URL と合言葉があるまで送信はしません。Safari のサイトデータや履歴を消すと、これらのキーも消えます。機種変更やデータ削除の前に「書き出す」で控えを取ってください。

## スプレッドシート連携（任意）

設定しなくても、アプリはそのまま使えます。連携するときは、端末が正本で、スプレッドシートはコピーです。

変更のたびに、端末内のキューへイベントを積み、送れるときにまとめて POST します。`{ok:true}` が返ったイベントだけをキューから外します。それ以外（オフライン、合言葉の不一致、通信失敗）は残し、あとで送り直します。送り直すタイミングは、アプリを開いたとき、オンラインに戻ったとき、画面が再表示されたとき、そして次の変更のあとです。URL と合言葉を保存したときも、溜まっている分を送ろうとします。

設定画面には、最終送信（日本時間）、保留件数、最後のエラーが出ます。「接続テスト」は `{type:"ping"}` を送り、`{ok:true, pong:true}` なら成功です。「全データを送り直す」は、いまある支出と、金額のある予算を送り直します。

シートは、最初の書き込みのときに作られます。

**支出**（ID ごとに 1 行）

| ID | 日付 | 月 | カテゴリ | 金額 | メモ | 更新日時 | 削除 |
| --- | --- | --- | --- | --- | --- | --- | --- |

アプリで支出を削除しても行は消えません。削除列が TRUE になり、更新日時が更新されます。まだその ID の行がなければ、ID と削除 TRUE の行を追加します。

**予算**（月とカテゴリ名の組み合わせで 1 行）

| 月 | カテゴリ | 予算額 | 更新日時 |
| --- | --- | --- | --- |

届いた `updatedAt` が、行にある更新日時より古いときは、そのイベントを無視します。同じ時刻か、より新しい時刻なら書き込みます。比較できない値が入っているときは、届いた内容を書きます。

次の動作は、画面とシートでタイミングが違います。

- 「前月の予算をコピー」は入力欄を埋めるだけです。シートへ送るのは「保存」を押したときで、変わったカテゴリだけです。金額を消して保存すると、そのカテゴリは 0 として送られます。
- カテゴリを追加しただけでは、シートに行は出ません。そのカテゴリで支出を記録するか、1円以上の予算を保存すると、カテゴリ名が載ります。名前を変えると、関連する支出と予算を新しい名前で送り、古い名前の予算額は 0 になります。削除すると、残った支出のカテゴリは「不明」になり、そのカテゴリの予算額は 0 になります。

手順の詳細は [gas/SETUP.md](gas/SETUP.md) です。概要だけ書くと、スプレッドシートの拡張機能から Apps Script を開き、`gas/Code.gs` を貼り、スクリプト プロパティ `SYNC_TOKEN` に合言葉を入れ、ウェブアプリとしてデプロイします。実行するユーザーは「自分」、アクセスできるユーザーは「全員」です。表示された `/exec` で終わる URL と、同じ合言葉を、アプリの設定に入力します。

## セキュリティ

このリポジトリに、送信先 URL、合言葉、支出の中身は置きません。合言葉は、Apps Script のスクリプト プロパティ `SYNC_TOKEN` と、入力した端末の `budget-app-sync-v1` だけにあります。

ウェブアプリのアクセスは「全員」です。知っている人は URL を開けますが、書き込みは合言葉が一致したリクエストだけです。URL と合言葉は、リポジトリやチャットに書かないでください。

「書き出す」でできる JSON は支出データです。コミットしないでください。`.gitignore` は `budget-data.json` と `*.export.json` を無視します。アプリが付けるファイル名は `budget-日付.json` なので、それも自分でコミットしないでください。

## 開発とテスト

依存パッケージもビルドもありません。リポジトリのルートで次を実行します。

```sh
node test/sync.test.js
```

`sw.js` がキャッシュするのは `./`、`index.html`、`sync.js`、`manifest.webmanifest`、`icon-180.png`、`icon-192.png`、`icon-512.png` です。これらを変えたら、`CACHE` を今の `budget-app-v2` から別の名前に上げてください。新しいサービスワーカーが有効になると、それ以外のキャッシュは削除されます。
