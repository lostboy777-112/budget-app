# スプレッドシート連携の設定

予算アプリの記録は、これまでどおり iPhone の中に保存されます。この手順は、そのコピーを Google スプレッドシートにも残したいときだけ使います。設定しなくても、アプリはそのまま使えます。

合言葉とウェブアプリの URL は、あなただけが知っていれば十分です。GitHub のリポジトリ、メール、チャット、スクリーンショットには書かないでください。アプリに入力した値は、その端末の中だけに保存されます。

## 1. 合言葉を決める

長くて、ほかのサービスで使っていない文字列にしてください。このあと、Apps Script のスクリプト プロパティ `SYNC_TOKEN` と、アプリの「合言葉」の両方に、同じ文字列を入れます。

## 2. スプレッドシートを用意する

パソコンでも iPhone でもできます。パソコンのほうが、Apps Script の画面は操作しやすいです。

1. [Google スプレッドシート](https://sheets.google.com/)で、新しいスプレッドシートを作ります。
2. 名前は、自分に分かるもの（例: 予算のコピー）にしてください。
3. メニューの **拡張機能** → **Apps Script** を開きます。

## 3. スクリプトを貼る

1. 最初から入っている `コード.gs`（または `Code.gs`）の中身を、すべて消します。
2. このリポジトリの `gas/Code.gs` を開き、中身をすべてコピーして貼り付けます。
3. 保存します（フロッピーのアイコン、または Ctrl+S / ⌘S）。

`Code.gs` に合言葉や支出の金額を書き足さないでください。合言葉は、次のプロパティだけに入れます。

## 4. 合言葉をスクリプト プロパティに入れる

1. 左の **プロジェクトの設定**（歯車）を開きます。
2. 下の方にある **スクリプト プロパティ** で **スクリプト プロパティを追加** を押します。
3. プロパティは `SYNC_TOKEN` と入力します。大文字・小文字もこのとおりにしてください。
4. 値に、手順 1 で決めた合言葉を入れます。
5. **スクリプト プロパティを保存** を押します。

## 5. ウェブアプリとして公開する

1. 右上の **デプロイ** → **新しいデプロイ** を開きます。
2. 歯車の **種類の選択** で **ウェブアプリ** を選びます。
3. 次のように設定します。
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: 全員
4. **デプロイ** を押します。
5. Google の確認が出たら、許可します。自分のスプレッドシートを更新するための確認です。
6. 表示された **ウェブアプリの URL** をコピーします。`/exec` で終わる URL を使ってください。

コードをあとから直したときは、**デプロイを管理** から **新しいデプロイ** を作り直してください。URL が変わることがあります。変わったら、アプリの送信先 URL も差し替えます。

## 6. アプリに URL と合言葉を入れる

1. iPhone で予算アプリを開きます（ホーム画面に追加したもので大丈夫です）。
2. 右上の **設定**（☰）を開きます。
3. **スプレッドシート連携** に、コピーした URL と、同じ合言葉を入力します。
4. **接続テスト** を押します。「接続できました」と出れば届いています。
5. それまでの記録もシートへ載せるときは、**全データを送り直す** を押します。

シート「支出」と「予算」は、最初の送信のときに作られます。見出しの行も自動で付きます。

## 7. 届いたデータの見方

- **支出** は ID ごとに 1 行です。アプリで削除しても行は消えず、**削除** 列が TRUE になります。
- **予算** は「月」と「カテゴリ」の組み合わせで 1 行です。
- 同じ記録が古い時刻で届いたときは、シート側の新しい行を上書きしません。

## うまくいかないとき

- 「合言葉が一致しません」と出る: アプリの合言葉と、`SYNC_TOKEN` の値が同じか確認します。プロパティを変えたあとは、ウェブアプリを新しいデプロイにし直します。
- 接続テストが失敗する: URL が `/exec` で終わっているか、アクセスできるユーザーが「全員」かを確認します。
- 記録がシートに増えない: アプリはオフラインでも使えます。電波が戻ってアプリを開くと、残っている分を送り直します。設定の状態欄に、最後に送れた時刻、残っている件数、最後のエラーが出ます。
